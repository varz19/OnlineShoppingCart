# Online Shopping Cart Management System

This is my Java project for managing an online shopping cart.

The program allows users to add and remove products, display product details, calculate the total price, and generate a bill.

The project includes three types of products:
- Electronic Products
- Clothing Products
- Food Products

I also used Java concepts such as:
- Classes and Objects
- Inheritance
- Encapsulation
- ArrayList
- Exception Handling
- Lambda Expressions
- Streams (Filter and Sort)

I created this project to practice Java programming and improve my understanding of object-oriented programming.
